About This Project

A complete end-to-end Machine Learning project — from raw data to a deployed web app.

🎯 Project Overview

LoanSense AI is a Loan Approval Prediction System built as a machine learning portfolio project. It predicts whether a bank loan application will be approved or rejected based on applicant data such as income, credit history, loan amount, and demographic details.

The system uses a trained {{ model_name }} model with an accuracy of {{ model_acc }}% on the test set.

🔄 ML Pipeline

1
Data Collection

614-row Loan Prediction dataset with 11 features (mirrors Kaggle dataset).

2
Preprocessing

Handle missing values (mode/median fill), label encoding, standard scaling.

3
Model Training

Two models trained: Logistic Regression and Random Forest (80/20 split).

4
Evaluation

Accuracy, confusion matrix, precision/recall, and 5-fold cross-validation.

5
Deployment

Best model saved as model.pkl and served via Flask REST API.
